AutoUnlock installation guide
=============================

1. Requirements on the target PC
  1. Windows 11 x64 with a Bluetooth adapter that supports BLE.
  2. .NET 10 Runtime (x64). Only the ".NET Runtime" is needed, not Desktop/ASP.NET:
     https://dotnet.microsoft.com/download/dotnet/10.0
     (needed by the service and helper; the Manager includes its own runtime)
  3. The latest Visual C++ Redistributable (x64, needed by the credential provider):
     https://aka.ms/vs/17/release/vc_redist.x64.exe
  4. Install as an administrator.

2. Installation
  1. Put the whole folder (or the unzipped package) in a permanent location, e.g. C:\AutoUnlock-pkg.
  2. Open PowerShell as administrator, go to that folder and run:

       Get-ChildItem -Recurse | Unblock-File
       Set-ExecutionPolicy -Scope Process Bypass
       .\scripts\install.ps1

     The first line removes the "downloaded from another computer" mark; otherwise Windows
     may block the scripts and the DLL.
     The installer's messages follow the Windows display language (Chinese / English / Spanish;
     any other language uses English).
  3. When it finishes, the Manager starts automatically (blue signal-lock icon in the tray).
     The service does not start until the configuration is filled in; that is expected.
  4. In the Services console the service is listed as "AutoUnlock Proximity Unlock".

3. First-time setup
  1. Pair the phone/watch with this PC over Bluetooth first
     (or use "Pair a new device…" on the Manager's Configuration page).
  2. On the Manager's Configuration page:
     - choose the target device in "Bluetooth device";
     - enter this PC's Windows user name and password;
     - click "Save changes".
  3. Click "Start service" on the Overview page, or run in an administrator PowerShell:
       Start-Service AutoUnlockService

4. Language
  Manager → Settings → Language: Use system language / 中文 / English / Español.
  The change applies right away, also to lock prompts, notifications and new log entries.

5. Troubleshooting
  - Service logs: C:\ProgramData\AutoUnlock\logs\ (also on the Manager's Logs page)
  - Event Viewer → Windows Logs → Application, source AutoUnlock
  - Uninstall: run .\scripts\uninstall.ps1 in an administrator PowerShell
    (it asks whether to delete the configuration and logs)
