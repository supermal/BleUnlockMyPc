BleUnlock 安装说明
==================

一、目标电脑的前提
  1. Windows 11 x64，带支持 BLE 的蓝牙适配器。
  2. .NET 10 运行时（x64），只需「.NET Runtime」，不需要 Desktop/ASP.NET：
     https://dotnet.microsoft.com/download/dotnet/10.0
     （服务与助手需要；管理器已自带运行时）
  3. 最新的 Visual C++ 运行库（x64，凭据提供程序需要）：
     https://aka.ms/vs/17/release/vc_redist.x64.exe
  4. 用管理员身份安装。

二、安装
  1. 把整个文件夹（或 zip 解压后）放到一个固定位置，例如 C:\BleUnlock-pkg。
  2. 以「管理员」打开 PowerShell，进入该文件夹后依次执行：

       Get-ChildItem -Recurse | Unblock-File
       Set-ExecutionPolicy -Scope Process Bypass
       .\scripts\install.ps1

     第一行解除「来自其他电脑」的下载标记，否则脚本和 DLL 可能被系统拦截。
     安装脚本的提示语言跟随 Windows 显示语言（中文 / English / Español，其他语言用英语）。
  3. 安装完成后服务和管理器都会自动启动（托盘里的蓝色信号锁图标）。
     新电脑还没有选择设备时，服务以「未配置」状态运行，不会锁屏也不会解锁，
     管理器会直接打开设置向导。
  4. 在「服务」管理工具中，服务显示为「BleUnlock Proximity Unlock」。

三、首次配置（设置向导，共 3 步）
  1. 选择解锁设备：列表里是已与这台电脑配对的设备。还没配对的话，点「配对新设备…」
     或「打开 Windows 蓝牙设置」；点「不知道怎么配对？」可以看到 Apple Watch、iPhone、
     安卓手机、手环各自的配对方法。显示「不支持」的设备没有身份密钥，不能用于解锁。
  2. 填写这台电脑的 Windows 用户名和密码（微软账户填邮箱；密码不是 PIN）。
     也可以点「暂不填写」：这样只会自动锁屏，回来不会自动解锁。
  3. 保存后立即生效，不用重启服务。
  向导可以跳过；之后在「概览」页点「运行设置向导」，或在「配置」页手动填写。
  安装后不用重启电脑：下一次锁屏时，锁屏界面就会加载 BleUnlock，回来即可自动解锁。

四、语言
  管理器「设置」页 →「语言」：跟随系统 / 中文 / English / Español。
  切换后立即生效，同时用于锁屏提示、通知和之后写入的日志。

五、出问题时
  - 服务日志：C:\ProgramData\BleUnlock\logs\（管理器「日志」页可直接查看）
  - 事件查看器 → Windows 日志 → 应用程序，来源 BleUnlock
  - 卸载：管理员 PowerShell 执行 .\scripts\uninstall.ps1（会询问是否删除配置与日志）
